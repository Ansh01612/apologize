# Proposed Her

This project is a small romantic web page built with HTML, CSS, and JavaScript.

## Live website

Published on GitHub Pages:

https://ansh01612.github.io/apologize/

## Run locally

From the project folder, start a local web server:

```bash
cd /e/love
python -m http.server 8000
```

Then open this in your browser:

```text
http://localhost:8000/
```

## Project files

- `index.html` - homepage
- `no1.html` - first no page
- `no2.html` - second no page
- `no3.html` - third no page
- `yes.html` - success page
- `style.css` - styling
- `script.js` - small interactive effect

## Notes

This is a static website, so no backend is required. It can be hosted easily on GitHub Pages.
